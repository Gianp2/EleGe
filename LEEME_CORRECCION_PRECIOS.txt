Lavadero eLeGe - ajuste de dictado y campos de importes

Cambios:
- El campo de precio y el de seña permiten quedar vacios mientras se editan.
- Al seleccionar un importe se marca el valor anterior para reemplazarlo de una sola vez.
- El precio dictado reconoce numeros (12000, 12.000, 12 mil) y palabras (doce mil, quince mil, veinticinco mil).
- Reconoce "pantalon" en singular.
- Si el dictado dice un total para varias prendas, exige revisar el precio unitario en lugar de multiplicarlo por error.
- El pedido se guarda solo al confirmar manualmente.

IMPORTANTE: Probado el analizador de frases y sintaxis de TS/TSX. No se pudo ejecutar la instalacion de dependencias ni compilar el proyecto integral en este entorno. Probalo localmente antes de publicar.

Instalacion:
1) Extraer en carpeta nueva de prueba, no sobrescribir el proyecto en uso.
2) Copiar el .env.local desde la carpeta original (no incluido por seguridad).
3) Ejecutar npm ci; npx tsc --noEmit; npm run build; npm run dev.
4) Probar precios por teclado y dictado con un pedido ficticio, sin confirmarlo en produccion.
